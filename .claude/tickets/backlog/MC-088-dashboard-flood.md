# MC-088 — Show flood extent/water level on the dashboard

- **Status:** TODO
- **Board:** backlog
- **Type:** feature
- **Milestone:** MVP v1

## Why it's parked
"Banjir" was a dock row from MC-078 marked CONTOH — a placeholder with no
data behind it, removed by MC-087 along with Penduduk and Lahan because a
button that opens nothing is worse than no button. The idea is real (flooding
is one of Indonesia's most frequent hazards, alongside fire, volcanoes,
earthquakes and landslides) but has had no source research at all yet.

## Before scheduling
- Find a credible, near-real-time flood/water-level source for Indonesia —
  BMKG's own site, BNPB's DIBI, or a satellite-derived extent product — and
  check its licence the way MC-084/MC-085 did for MAGMA and BMKG's quake feeds.
- Decide what a "flood" point or polygon means on the map: a gauge reading, a
  reported incident, or a detected extent — each is a different data shape and
  a different popup.
- Same theme as Titik Api / Gunung Api / Gempa / Gerakan Tanah (MC-086): one
  hazard, one line in the Situasi panel, once MC-087's shared panel exists.
