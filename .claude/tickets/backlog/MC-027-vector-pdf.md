# MC-027 — Vector (selectable-text) PDF export

- **Status:** BACKLOG
- **Board:** backlog
- **Type:** feature
- **Milestone:** post-v1

## Why parked
The current raster export is fine for print. This matters for accessibility and
for anyone editing the PDF afterwards.

## Functionality
- Draw text, legend and frames as real PDF vector content instead of a bitmap.
- The map itself can stay raster; the furniture around it should not be.

## Acceptance criteria
- [ ] Title and legend text is selectable in the exported PDF.
- [ ] Output still matches the on-screen layout.
